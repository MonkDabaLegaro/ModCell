# Modificador de Teléfono

Aplicación para gestión integral de aplicaciones móviles desde PC usando ADB.

## Instalación

1. Instalar Python 3.9+.
2. Instalar dependencias: `pip install pyqt5 cryptography`
3. Instalar ADB y scrcpy (ver instrucciones en docs/).
4. Ejecutar: `python main.py`

## Funcionalidades

- Detección de dispositivos Android.
- Lista, instalación, desinstalación y reparación de apps.
- Mirroring de pantalla.
- Gestión de permisos.
- Backups y restores.

## Estructura

- src/: Código fuente.
- tests/: Pruebas.
- docs/: Documentación.
